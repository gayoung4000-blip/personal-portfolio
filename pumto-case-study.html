PROJECT · UX/UI · SERVICE DESIGN

아이의 미술 경험을 찾는 순간부터
성장을 기록하는 과정까지

↗ PROJECT OVERVIEW

  • 프로젝트 유형  ·  UX/UI 개인 프로젝트
  • 주요 타깃  ·  자녀의 미술교육을 고민하는 보호자
  • 담당 역할  ·  UX 리서치, 서비스 기획, UI 디자인, 프로토타이핑
  • 사용 도구  ·  Figma, React, Vercel

↗ PROBLEM

보호자는 아이에게 맞는 미술학원을 찾기 위해 여러 채널을 오가며 정보를 비교해야 합니다.
학원에 다니기 시작한 후에도 작품과 성장 과정이 사진첩이나 메신저에 흩어져 체계적으로 확인하기 어렵습니다.

↗ SOLUTION

품토는 학원 탐색과 예약, 작품 기록, 성장 확인을 하나의 흐름으로 연결했습니다.

  • 지역과 수업 조건에 맞는 미술학원 탐색
  • 학원 정보와 실제 후기를 통한 비교
  • 간편한 수업 예약 및 일정 확인
  • 아이의 작품을 날짜와 활동별로 기록
  • 누적된 기록을 통해 성장 과정 확인

↗ DESIGN GOAL

보호자에게는 신뢰할 수 있는 선택을, 아이에게는 오래 남는 성장 기록을 제공합니다. 정보를 빠르게 비교할 수 있도록 화면 구조를 단순화하고, 아이의 활동과 작품이 중심에 보이도록 따뜻하고 친근한 비주얼을 적용했습니다.

↗ MY CONTRIBUTION

사용자 문제 정의부터 정보 구조, 핵심 사용자 흐름, 와이어프레임과 UI 디자인까지 전 과정을 주도했습니다. 이후 React를 활용해 주요 화면을 구현하며 디자인이 실제 서비스에서 어떻게 작동하는지도 확인했습니다.

↗ WHAT I LEARNED

이번 프로젝트를 통해 보기 좋은 화면보다 사용자의 선택과 행동이 자연스럽게 이어지는 구조가 먼저 설계되어야 한다는 점을 배웠습니다. 특히 학원 탐색, 예약, 작품 기록처럼 서로 다른 기능도 사용자의 목적을 기준으로 연결하면 하나의 일관된 경험이 될 수 있다는 것을 알게 되었습니다. 또한 직접 구현하는 과정에서 컴포넌트의 재사용성과 화면 확장 가능성까지 고려해야 완성도 높은 디자인 시스템을 만들 수 있다는 점을 배웠습니다.

↗ GROWTH POINT

처음에는 많은 정보를 한 화면에 보여주는 데 집중했지만, 반복적인 검토를 통해 사용자가 가장 먼저 확인해야 할 정보의 우선순위를 다시 정리했습니다. 그 결과 기능을 추가하는 것보다 중요한 정보를 선별하고 흐름을 단순화하는 것이 더 나은 UX를 만든다는 것을 체감했습니다.

작품 한 장이 기록이 되고, 기록이 아이의 성장을 보여주도록.

품토는 아이의 오늘을 담아 내일의 성장을 발견할 수 있는 미술교육 경험을 제안합니다.
